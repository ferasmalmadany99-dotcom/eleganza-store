---
name: تشغيل معاينة المتجر
description: التمييز بين توقف معاينة متجر الويب ومشكلة فعلية في بيانات المنتجات
---

قد تبدو معاينة متجر Eleganza فارغة إذا توقفت خدمة الويب أو API، مع بقاء المنتجات سليمة. بعد إعادة تشغيل الخدمتين، ظهرت المنتجات الـ13 في المعاينة وعاد مسار الكتالوج بـ200.

**Why:** كانت قائمة المنتجات فارغة للمستخدم، لكن فحص API أظهر 13 منتجًا؛ إعادة تشغيل خدمتي المتجر والـAPI أعادت ظهورها دون تعديل بيانات الكتالوج.

**How to apply:** قبل تغيير استعلامات الكتالوج أو بياناته عند فراغ المعاينة، تحقق من حالة خدمتي الويب والـAPI، ثم افحص استجابة `/api/storefront/products`.

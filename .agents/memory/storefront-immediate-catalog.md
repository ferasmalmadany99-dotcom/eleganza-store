---
name: فتح المتجر فورًا
description: شرط المستخدم لظهور منتجات Eleganza مباشرة عند فتح متجر الويب
---

يريد المستخدم ظهور المنتجات فور فتح متجر Eleganza، دون انتظار استجابة API. اعرض القائمة المحلية فورًا، واستعد آخر كتالوج ناجح مخزنًا محليًا ثم حدّثه من الخادم.

**Why:** طلب المستخدم منع تكرار اختفاء المنتجات عند فتح المتجر.

**How to apply:** عند تعديل بدء تشغيل متجر الويب أو جلب المنتجات، حافظ على العرض الفوري مع تحديث البيانات من API بعده.

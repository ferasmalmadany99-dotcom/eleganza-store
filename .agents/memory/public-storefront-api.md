---
name: مسار مخزون المتجر العام
description: قاعدة ترتيب مسارات القراءة العامة للمتجر مع حماية Clerk في خادم Eleganza
---

مسارات القراءة العامة التي يحتاجها متجر الزبائن يجب تسجيلها على التطبيق قبل `clerkMiddleware`، بينما تُضاف حماية المصادقة والصلاحيات صراحةً إلى مسارات الإدارة.

**Why:** وضع المسار العام داخل راوتر محمي أدى إلى استجابات 401 متقطعة في المعاينة، رغم أن المسار كان مكتوبًا قبل `router.use(requireAuth)` داخل راوتره.

**How to apply:** استخدم راوترًا عامًا مستقلًا لمسارات الكتالوج/المخزون، ثبّته قبل Clerk، ولا تُرجع منه أي حقول حساسة أو عمليات كتابة.
